# 📚 One-Line Revision

## LLM

A deep learning model trained to predict the next token.

---

## Transformer

A neural network architecture based on Self-Attention.

---

## Tokenization

Converts text into tokens and Token IDs.

---

## Parameters

Long-term learned knowledge stored as weights.

---

## Context Window

Temporary memory used during a conversation.

---

## Pre-training

Learns language from massive datasets.

---

## Fine-tuning

Learns instructions and specialized tasks.

---

## RLHF

Improves responses using human feedback.

---

## Greedy Decoding

Always selects the highest probability token.

---

## Temperature

Controls randomness.

---

## Top-k

Chooses among the top *k* most likely tokens.

---

## Top-p

Chooses from the smallest set of tokens whose cumulative probability reaches *p*.

---

# 🔄 Complete LLM Pipeline

```text
User Prompt
      │
Tokenizer
      │
Token IDs
      │
Embeddings
      │
Transformer
      │
Next Token Prediction
      │
Generated Response
```

# 🧠 Quick Interview Revision

- LLM → Predicts the next token.
- Transformer → Uses Self-Attention.
- Token → Smallest processing unit.
- Parameters → Long-term knowledge.
- Context Window → Short-term memory.
- Fine-tuning → Instruction following.
- RLHF → Better human-friendly responses.
- Temperature → Creativity.
- Top-k → Fixed candidate tokens.
- Top-p → Probability-based candidate tokens.
