# Temperature

## What is Temperature?

Temperature is a generation parameter that controls the randomness or creativity of an LLM's output.

## Low Temperature (e.g., 0.1)

- More deterministic
- More consistent
- Best for:
  - Coding
  - Mathematics
  - Medical reports
  - Summarization

## High Temperature (e.g., 1.5)

- More creative
- More diverse responses
- Best for:
  - Story writing
  - Brainstorming
  - Poetry
  - Marketing

## Key Takeaway

Temperature controls randomness, not intelligence.

## Interview Note

Increasing temperature does not make the model smarter. It only changes how randomly tokens are selected.
